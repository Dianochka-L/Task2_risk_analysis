# Тестовое задание (риски) — решение

Проверка гипотезы о первоначальном взносе (ПВ) как факторе платёжеспособности и предложение
по его использованию в Системе Принятия Решения (СПР).

## Структура

| Файл | Что внутри |
|:---|:---|
| `01_Аналитическая_записка.md` | Проверка гипотезы, выбор порога, раздел про ML, предложение в СПР, оценка эффекта |
| `02_Бизнес-требование_и_тест-кейсы.md` | Бизнес-требование для разработчиков |
| `experiments.ipynb` | Все эксперименты и графики (выполнен, выводы сохранены) |
| `queries.sql` | SQL-скрипты под каждую манипуляцию с данными папки БД, так как они требовались по тексту задания |
| `data/` | Исходные данные (`dataset.csv` и папка `БД/`) |

## Ключевые выводы

- Гипотеза подтверждена.. ПВ ранжирует просрочку (Gini 0.37) не хуже действующего pd (0.33),
  зависимость монотонная
- Рабочий порог ПВ >= 0.32 выводит ретро-портфель на просрочку 0.86%
- При равной цели по риску ПВ одобряет 47% больше объёма, чем pd
- ML даёт + 10 п.п. одобрения — рекомендуется как следующая итерация
- На актуальном потоке правило меняет одобрение с 23.9% до 11.7%; 155 отклонённых заявок с
  высоким ПВ — потенциал роста
